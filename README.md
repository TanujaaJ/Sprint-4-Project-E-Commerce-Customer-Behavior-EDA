# Sprint-4-Project-E-Commerce-Customer-Behavior-EDA

## Description
This project focuses on Exploratory Data Analysis (EDA) of e-commerce customer behavior. The goal is to analyze patterns in customer purchasing habits, order frequency, basket size, and customer retention to extract actionable business insights.

## Data Source
E-Commerce Customer Behavior Dataset(Olist Brazilian E-Commerce Dataset)

## Methods and Tools
- Python (Pandas, Matplotlib)
-  SQL
- Jupyter Notebook / Google Colab

## Key Findings
- High delivery success rate present in this business with steady growth showing upward trend.
- Top performing categories are Health & Beauty, Watches & Gifts, Sports & Leisure with high average rating of 4 and above.
- The customer base is heavily concentrated in Southeastern Brazil
- There is a clear negative correlation between delivery time and customer satisfaction.
